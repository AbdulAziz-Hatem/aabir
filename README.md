# عَابِر | Aabir 📶

> **«اعبُر إلى شبكتك بلمحة بصر»**

تطبيق أندرويد حر ومفتوح المصدر (FOSS) مبني بالكامل بلغة **Kotlin** وبإطار **Jetpack Compose الحديث (Material3 / Material You v3)**، مخصص لمسح كروت شبكات الواي فاي (Hotspot Vouchers) ضوئياً مع توجيه حركي صوتي ذكي (Guided Vision) وتسجيل الدخول التلقائي في بوابات راوتر ميكروتك (Captive Portals)، مصمم وفق أعلى معايير إمكانية الوصول الشاملة للمكفوفين ومستخدمي قارئات الشاشة (TalkBack / Jieshuo)، ومرخص برخصة **GNU General Public License v3.0 (GPLv3)**.

---

## 🏛️ المعمارية الهندسية النظيفة (Clean Architecture)

تمت هيكلة المشروع وفق أصول العمارة النظيفة ومبادئ SOLID، مع عزل الشاشات والمكونات لمنع تضخم الكود وضمان أعلى مستويات قابلية الصيانة:

```text
com.abdulaziz.aabir/
├── MainActivity.kt                # نقطة الانطلاق وإدارة Compose و Edge-to-Edge والأذونات
├── model/
│   ├── Models.kt                  # كائنات البيانات والحالات (VoucherRecord, AppSettings, AppTab)
│   └── StorageManager.kt          # مدير التخزين الدائم الآمن للإعدادات والسجل
├── feedback/
│   └── FeedbackManager.kt         # محرك النغمات المحسوبة مسبقاً (PCM Synthesis) والاهتزاز و TTS
├── network/
│   └── MikrotikClient.kt          # محرك الربط الشبكي الصريح وكشف الـ DHCP Gateway الحقيقي
├── camera/
│   ├── CameraPreview.kt           # ربط عتاد CameraX وعزل الشجرة عن TalkBack
│   └── VoucherAnalyzer.kt         # محرك الرؤية الموجهة (Guided Vision) وفلترة الـ OCR
└── ui/
    ├── Theme.kt                   # سمات وألوان Material You v3 الداكنة والفاتحة
    ├── MainScreen.kt              # المنسق العام للشاشات والـ Scaffold والـ Lifecycle
    ├── screens/
    │   ├── ScanTab.kt             # شاشة المسح والكاميرا وإدخال الكود
    │   ├── HistoryTab.kt          # شاشة سجل الكروت وإعادة الدخول ومسح السجل
    │   └── SettingsTab.kt         # شاشة الإعدادات الشاملة المجمعة
    └── components/
        ├── AboutCard.kt           # بطاقة الأكورديون القابلة للتمدد والطي (Material You)
        └── SensorTestbed.kt       # منصة الفحص الحسي المباشر (فلاش، صوت، اهتزاز)
```

## 🌟 الميزات الجوهرية والتحصينات الهندسية

1. **الرؤية الموجهة المكانية (Spatial Guided Vision):**
   - تحليل هندسي لحظي لأبعاد وموقع الكرت داخل إطار الكاميرا مع عازل زمني (3 ثوانٍ) لمنع الثرثرة.
   - إرشادات صوتية واضحة للمكفوفين: *(«اقترب بالهاتف قليلاً»، «ابتعد قليلاً»، «حرّك الهاتف لليمين/لليسار»، «ارفع/أنزل الهاتف»، «ثبّت يدك، جارٍ القراءة»)*.
   - صمت تام عندما يقع الكرت في البؤرة المركزية لعدم التشويش على قارئ الشاشة.

2. **تحكم عتادي صلب في الكاميرا والفلاش وحماية دورة الحياة:**
   - تحكم برمجي مباشر في الفلاش عبر مشغل عتاد الكاميرا (`CameraControl.enableTorch`) فيضيء تلقائياً عند فتح الكاميرا وينطفئ فور رصد الكود.
   - ربط كامل مع دورة حياة أندرويد (`LifecycleEventObserver`): إطفاء فوري للكاميرا والفلاش بمجرد مغادرة التطبيق إلى الشاشة الرئيسية أو التطبيقات الأخيرة لمنع استنزاف البطارية وحجز العتاد.
   - شاشة مسح غامرة بالكامل تخفي الترويسة وأزرار التنقل السفلية لحماية الكفيف من اللمسات العرضية.

3. **كشف البوابة والدخول التلقائي في ميكروتك (Captive Portal Auto-Submit):**
   - كشف فوري لعنوان بوابة الراوتر الحقيقية من عتاد الواي فاي (`WifiManager.dhcpInfo.gateway`) دون أي تخمين يدوي.
   - ربط المقابس الشبكية بالواي فاي عبر `ConnectivityManager.bindProcessToNetwork` مع فك الارتباط الحتمي في كتلة `finally`.
   - دعم نمطي ميكروتك: (Single Username فقط الشائع في اليمن، ونمط Username = Password).
   - فحص محلي فوري لمنع أي تعليق أو تجمد ناتج عن طلبات الـ DNS الخارجية.

4. **توليد نغمات PCM مسبقة ومحسوبة بالذاكرة (Pre-computed PCM Buffers):**
   - استبدال إنشاء الـ Threads العشوائي بتوليد مسبق للنغمات الترددية في الذاكرة العشوائية لتشغيلها في أجزاء من الملي ثانية وحماية الذاكرة من الانهيار.
   - رادار صوتي متباعد وهادئ يتكرر كل **2.8 ثانية** ليؤكد يقظة الكاميرا دون إزعاج.

5. **واجهة Material You v3 متوافقة مع معايير الوصول (WCAG 2.2 AAA):**
   - ترويسة نقية خالية من أرقام الإصدارات لتقليل التشتت.
   - بطاقة "عن عابر والمطور" قابلة للتمدد والطي بسلاسة ناعمة (`AnimatedVisibility`).
   - وسوم العناوين (`heading()`) وأبعاد لمس قياسية (48dp) لكافة العناصر.

6. **جاهزية أندرويد 17 وتجريد اللغات الزائدة:**
   - تجريد ملفات الترجمة لأكثر من 80 لغة ميتة عبر `resourceConfigurations += ['ar', 'en']` لتقليص حجم الحزمة.
   - دعم محاذاة 16KB Page Alignment الإلزامية في أندرويد 15 و16 و17.
   - دعم كامل للتراجع التنبؤي (Predictive Back Gesture).

## 📦 حزم التطبيق المتاحة (Dual Flavors)

| الحزمة | المحرك المستخدم | حجم الـ APK التقريبي | متطلبات التشغيل |
| :--- | :--- | :--- | :--- |
| **النسخة الكاملة (Full)** | `com.google.mlkit:text-recognition` (Bundled) | ~15 - 18 MB | تعمل في أي مكان بدون اتصال إنترنت وبدون الحاجة لخدمات غوغل بلاي. |
| **النسخة الخفيفة (Lite)** | `play-services-mlkit-text-recognition` (Unbundled) | **~3 MB فقط!** | مخصصة لتوفير رصيد البيانات؛ يقوم النظام بتنزيل نموذج التعرف ديناميكياً عبر خدمات غوغل. |
