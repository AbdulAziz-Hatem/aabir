# كروتي هوت سبوت | Karty Hotspot 📶

تطبيق أندرويد حر ومفتوح المصدر (FOSS) مخصص لمسح كروت شبكات الواي فاي (Hotspot Vouchers) ضوئياً وتسجيل الدخول التلقائي في بوابات راوتر ميكروتك (Captive Portals)، مصمم وفق أعلى معايير إمكانية الوصول الشاملة للمكفوفين ومستخدمي قارئات الشاشة (TalkBack / Jieshuo).

---

## 🌟 الميزات الجوهرية

1. **التعرف الضوئي المحلي الصامت (Offline OCR):**
   - يعمل بالكامل محلياً على الهاتف دون الحاجة لأي اتصال إنترنت عبر محرك `Google ML Kit Text Recognition`.
   - خوارزمية ذكية تعزل خط كود الخدش الأكبر حجماً، وتتجاهل تلقائياً أرقام الهواتف التسويقية (77/73/71/70) والأرقام التسلسلية والشعارات.

2. **التسجيل التلقائي في ميكروتك (Hotspot Auto-Login):**
   - إرسال طلب `HTTP POST` فورياً إلى عنوان بوابة الراوتر بمجرد التقاط الرمز (`username=PIN&password=PIN`) دون الحاجة لفتح المتصفح أو التعامل مع صفحات الويب يدوياً.
   - كشف تلقائي وتجربة البوابات الأكثر شيوعاً (`10.0.0.1`، `192.168.88.1`، `172.16.0.1`) مع إمكانية التعيين اليدوي للبوابة من الإعدادات.

3. **هندسة التغذية اللمسية والصوتية (Accessibility Architecture):**
   - **نغمات ترددية نقية (Web Audio API):**
     - **نغمة النجاح:** كورد ثلاثي نقي متصاعد (C5 -> E5 -> G5) يوحي بالعبور السلس.
     - **نغمة الفشل:** تردد هابط حاسم من 280Hz إلى 110Hz ينبه بوجود خطأ اتصال أو كود غير صالح.
     - **رادار الكاميرا:** تكتكة ناعمة كل ثانية تُشعر الكفيف ببحث الكاميرا وتفاعلها الحي دون بقائه في صمت.
   - **أنماط اهتزاز متباينة (Haptic Patterns):**
     - نبضتان ناعمتان متتاليتان للنجاح `[90ms, 60ms, 160ms]`.
     - ثلاث نبضات قوية متقطعة للفشل `[240ms, 80ms, 240ms, 80ms, 240ms]`.
     - نبضة خفيفة عند قراءة الكود `[70ms]`.
   - **محرك تحويل النص إلى كلام (TTS Voices Engine):**
     - قائمة منسدلة داخل الإعدادات تسحب المحركات والأصوات المثبتة على الهاتف لاختيار الصوت المفضل.
     - مفتاح تبديل رئيسي لتفعيل/إلغاء التنبيهات الصوتية الناطقة حسب رغبة المستخدم.
     - زر فوري لتجربة نطق الصوت المختار.
   - **إشعارات Toast المتوافقة:**
     - ظهور Toast على الشاشة مصحوب بإعلان فوري لقارئات الشاشة عبر `aria-live="assertive"`.

4. **توقيع رقمي موثق (Digitally Signed):**
   - يتم بناء الحزمة وتوقيعها رقمياً بمفتاح RSA-4096 المعتمد للمطور عبر GitHub Actions لضمان أمان التثبيت والتحديثات المستقبلية.

## 🛠️ التقنيات المستخدمة

- **الواجهة:** React 19, TypeScript, Tailwind CSS, Lucide Icons.
- **إطار العمل الأصيل:** Capacitor 8.5 (Android Platform).
- **محرك القراءة:** `@capacitor-mlkit/text-recognition`.
- **الصوتيات والاهتزاز:** Web Audio API, Web Speech API, Navigator Vibration API.
- **التشغيل المستمر (CI/CD):** GitHub Actions مع تجميع Gradle التلقائي وتوقيع PKCS12.
