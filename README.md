# عَابِر | Aabir 📶

> **«اعبُر إلى شبكتك بلمحة بصر»**

تطبيق أندرويد حر ومفتوح المصدر (FOSS) مبني بالكامل بلغة **Kotlin** وبإطار **Jetpack Compose الحديث (Material3)**، مخصص لمسح كروت شبكات الواي فاي (Hotspot Vouchers) ضوئياً وتسجيل الدخول التلقائي في بوابات راوتر ميكروتك (Captive Portals)، مصمم وفق أعلى معايير إمكانية الوصول الشاملة للمكفوفين ومستخدمي قارئات الشاشة (TalkBack / Jieshuo).

---

## 🌟 الميزات الجوهرية والمعمارية الأصيلة

1. **معمارية أندرويد نقية (Pure Native Kotlin & Jetpack Compose):**
   - تم الاستغناء نهائياً عن متصفحات الويب وحزم كاباسيتور، ليصبح التطبيق خفيفاً وفائق السرعة دون استهلاك لموارد المعالج والبطارية.
   - واجهة عصرية تعتمد Material3 والتراجع التنبؤي (Predictive Back Gesture) والتوافق الكامل مع حواف الشاشة (Edge-to-Edge).

2. **تحكم عتادي مباشر في الكاميرا والفلاش (CameraX & Camera2):**
   - فتح فوري ومباشر للكاميرا الخلفية عبر مكتبة `CameraX` دون تصادم عتادي.
   - تحكم برمجي مباشر في الفلاش من مشغل العتاد (CameraControl) لضمان إضاءة موضع الخدش وإطفائه آلياً فور العثور على الكود.

3. **التعرف الضوئي التكيفي الذكي (Smart OCR Heuristics):**
   - عزل خط كود الخدش الأكبر حجماً ووضوحاً باستخدام `Google ML Kit Text Recognition`.
   - استبعاد حتمي لكافة أرقام الهواتف (موبايل، يو، سبأفون، واي، والثابت)، والأرقام التسلسلية الطويلة، والأسعار.
   - مرونة كاملة في أطوال الأرقام (من 4 إلى 16 خانة) دون الحاجة لمعرفة طول كرت الشبكة مسبقاً.

4. **كشف البوابة والدخول التلقائي في ميكروتك (Captive Portal Auto-Submit):**
   - كشف فوري لعنوان بوابة الراوتر الحقيقية من عتاد الواي فاي (`WifiManager.dhcpInfo.gateway`) دون أي تخمين يدوي.
   - ربط المقابس الشبكية بشبكة الواي فاي الصريحة لتجاوز عزل أندرويد للشبكات المقيدة.
   - دعم نمطي ميكروتك: (Single Username فقط الشائع في اليمن، ونمط Username = Password).
   - فحص محلي فوري لمنع أي تعليق أو تجمد ناتج عن طلبات الـ DNS الخارجية.

5. **هندسة التغذية اللمسية والصوتية (Accessibility Architecture):**
   - **نغمات حية نقية (Synthesized PCM Tones via AudioTrack):** كورد النجاح المتصاعد (C5 -> E5 -> G5)، نغمة الفشل الهابطة (280Hz -> 110Hz)، ورادار صوتي هادئ يتكرر كل **2.8 ثانية** لطمأنة الكفيف بيقظة الكاميرا دون أي إزعاج.
   - **أنماط اهتزاز متباينة:** نبضات مميزة لكل حدث عبر `VibrationEffect`.
   - **محرك تحويل النص إلى كلام (TTS):** دعم كامل للغة العربية واختيار المحرك الصوتي المفضل ومفتاح للتعطيل عند الرغبة.
   - **واجهة مستخدم نظيفة لقارئ الشاشة:** حصر قسم "عن التطبيق والمطور" ومنصة الفحص الحسي داخل شاشة الإعدادات في موضع وحيد لمنع تشتت المؤشر.

6. **جاهزية أندرويد 17 ومحاذاة الذاكرة (16KB Page Sizes):**
   - تم ضبط تكوين الحزم لدعم محاذاة 16KB Page Alignment المتوافقة مع أحدث معالجات الهواتف وأنظمة أندرويد 15 و16 و17.

## 📦 حزم التطبيق المتاحة (Dual Flavors)

| الحزمة | المحرك المستخدم | حجم الـ APK التقريبي | متطلبات التشغيل |
| :--- | :--- | :--- | :--- |
| **النسخة الكاملة (Full)** | `com.google.mlkit:text-recognition` (Bundled) | ~15 - 18 MB | تعمل في أي مكان بدون اتصال إنترنت وبدون الحاجة لخدمات غوغل بلاي. |
| **النسخة الخفيفة (Lite)** | `play-services-mlkit-text-recognition` (Unbundled) | **~3 MB فقط!** | مخصصة لتوفير رصيد البيانات؛ يقوم النظام بتنزيل نموذج التعرف ديناميكياً عبر خدمات غوغل. |
