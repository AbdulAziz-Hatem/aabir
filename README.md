## 📖 نبذة عن المشروع (Overview)

**نِت بَاس (NetPass)** هو تطبيق أندرويد سيادي، حر، ومفتوح المصدر بالكامل (FOSS)، صُمم انطلاقاً من حاجة مجتمعية حقيقية لسد فجوة الوصول العادل والمستقل إلى شبكات الإنترنت المحلية. يتيح التطبيق للمستخدمين عامة، وللمكفوفين وضعاف البصر ومستخدمي قارئات الشاشة خاصة، قراءة كروت شبكات Wi-Fi وبطاقات الـ Hotspot ضوئياً وبدقة متناهية، والتسجيل التلقائي المباشر في بوابات MikroTik دون الحاجة لكتابة يدوية ودون الاعتماد على أي خوادم سحابية خارجية.

صُمم التطبيق باتباع فلسفة البرمجيات الأصيلة المستقرة: **كود نظيف، أداء عالي على العتاد المحدود، استقرار الذاكرة طويل المدى، وخلو كامل من الإعلانات وأدوات التتبع**.

## 🏛️ الركائز الهندسية الأربع (Core Engineering Pillars)

```text
┌────────────────────────────────────────────────────────────────────────┐
│                          NetPass Architecture                          │
├──────────────────┬──────────────────┬──────────────────┬───────────────┤
│ 1. الرؤية الموجهة │ 2. الصوت الرقمي  │ 3. الربط الشبكي   │ 4. الواجهة    │
│  (Guided Vision) │  (PCM Synthesis) │  (Core Network)  │   (Compose)   │
├──────────────────┼──────────────────┼──────────────────┼───────────────┤
│ • ML Kit Latin   │ • Pure Sine PCM  │ • Route Gateway  │ • Material 3  │
│ • Sweet-Spot Lock│ • Zero-Alloc Bus │ • Process Bind   │ • MVI / UDF   │
│ • 10 FPS Guard   │ • Pre-built Core │ • HTTP Captive   │ • WCAG 2.2    │
└──────────────────┴──────────────────┴──────────────────┴───────────────┘
```

### 1. محرك الرؤية الموجهة (Guided Vision Engine)
* **المسح المكتبي الذكي:** خوارزمية هندسية مدمجة تقيس استقرار الهاتف في الفضاء الثلاثي الأبعاد فوق الطاولة، وتوجه المستخدم بحركات حسية دقيقة خالية من الغموض (اقترب، ابتعد، حرّك لليسار/اليمين).
* **قفل البؤرة الذهبية (Sweet-Spot Auto-Lock):** التقاط تلقائي فوري للكود بمجرد توسط الكرت داخل بؤرة العدسة واستقرار اليد لمدة إطارين متتاليين.
* **حماية المعالج والبطارية:** حصر معدل الاستدلال الصوري في 10 إطارات بالثانية (10 FPS) لتجنب ارتفاع حرارة المعالج أو استنزاف البطارية أثناء البحث عن الكرت.

### 2. محرك التغذية الحسية والصوتية (Synthetic Audio & Haptics)
* **توليد صوتي رقمي أصيل (PCM Synthesis):** توليد نغمات التوجيه والرادار والنجاح والخطأ رياضياً عبر معادلات الجيب النقي (Pure Sine Waves) دون الحاجة لتخزين ملفات وسائط تضخم حجم التطبيق.
* **استقرار الذاكرة التام (Zero-Allocation Bus):** إعادة استخدام القنوات الصوتية الثابتة (`AudioTrack`) لحظر تسريب المقابض النيتف (Native Handle Exhaustion).
* **التوافق التام مع قارئات الشاشة:** دعم مرن لكافة محركات تحويل النص إلى كلام (TTS)، وتكامل سياقي كامل مع مختلف قارئات الشاشة على أندرويد.

### 3. محرك الربط الشبكي وبوابات Hotspot
* **كشف المسار الحقيقي (Default Route Gateway):** استخراج عنوان بوابة الراوتر الفعلي عبر جدول توجيه نظام أندرويد المعياري من `ConnectivityManager.getLinkProperties()`.
* **ربط العملية بالشبكة اللاسلكية (`bindProcessToNetwork`):** إجبار حزم البيانات على المرور عبر بطاقة Wi-Fi حتى في حالة إعلان النظام عن "شبكة بلا اتصال إنترنت" (Captive Portal Trap).
* **دعم أنماط التحقق المتعددة:** دعم بوابات MikroTik الشائعة (نمط اسم المستخدم المنفرد، ونمط اسم المستخدم المطابق لكلمة المرور).

### 4. معايير الوصول الشامل (Accessibility by Design)
* التزام صارم بمعايير **WCAG 2.2 AAA**.
* مساحات لمس قياسية لا تقل عن 48×48dp لكافة الأزرار وعناصر التحكم.
* دمج العناصر الدلالية (`mergeDescendants = true`) لمنع تشتت قارئات الشاشة.
* إعلانات لحظية عبر مناطق الأحداث الحية (`LiveRegionMode.Assertive`).

## 📦 حزم التطبيق (Distribution Flavors)

يوفر المستودع خيارين رئيسيين للبناء لتلبية كافة ظروف الاستخدام والاتصال:

| المعيار | حزمة أوفلاين الكاملة (`Full`) | الحزمة فائقة الخفة (`Lite`) |
| :--- | :--- | :--- |
| **محرك التعرف (OCR)** | `com.google.mlkit:text-recognition` (Bundled) | `play-services-mlkit-text-recognition` (Unbundled) |
| **حجم الحزمة (APK)** | **~21 ميجابايت** | **~2.7 ميجابايت فقط** |
| **الاتصال الخارجي** | أوفلاين بنسبة 100% ولا تتطلب أي خدمات مسبقة. | تستفيد من خدمات Google Play لتنزيل النموذج لمرة واحدة. |
| **حالات الاستخدام** | الهواتف الخالية من خدمات جوجل (MicroG/AOSP) ومناطق العزلة. | هواتف أندرويد الرسمية والمستخدمين ذوي باقات البيانات المحدودة. |

## 🔒 الأمان والخصوصية (Security & Privacy Manifest)

* **صفرية التتبع (Zero-Telemetry):** لا يضم التطبيق أي حزم تحليلات (Analytics)، أو تتبع أعطال خارجي (Crashlytics)، أو إعلانات نهائياً.
* **معالجة محلية بالكامل (100% On-Device):** لا تغادر صورة واحدة أو رمز كرت أو عنوان IP هاتف المستخدم؛ استدلال الكاميرا يتم محلياً على المعالج اللحظي، ومسار الشبكة محلي مباشرة بين الهاتف والراوتر.
* **حصر الصلاحيات (Minimal Permissions):** لا يطلب التطبيق إلا صلاحية الكاميرا للمسح (مع استمرارية العمل التامة عبر الإدخال اليدوي عند رفض الإذن)، وصلاحية الاهتزاز والشبكة المحلية.

## 🛠️ دليل البناء والتطوير (Building from Source)

### المتطلبات الأساسية:
* **JDK:** الإصدار 21 فما فوق (Java 21 LTS).
* **Android SDK:** CompileSdk 37، TargetSdk 35، MinSdk 24.
* **Build System:** Gradle 9.6.0 مع Android Gradle Plugin (AGP) 9.5.1.

### خطوات التجميع عبر الطرفية:

```bash
# 1. استنساخ المستودع
git clone https://github.com/AbdulAziz-Hatem/netpass.git
cd netpass

# 2. بناء نسخة الـ Full المدمجة (Debug)
./gradlew assembleFullDebug

# 3. بناء نسخة الـ Lite الخفيفة (Debug)
./gradlew assembleLiteDebug

# 4. بناء الحزم الموقعة للإنتاج (يتطلب تهيئة متغيرات بيئة التوقيع)
./gradlew assembleFullRelease assembleLiteRelease
```
